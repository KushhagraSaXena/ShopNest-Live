# 🛍️ ShopNest

**ShopNest** is a seamless, scalable eCommerce platform built with modern web technologies. It offers a rich shopping experience for users and a powerful admin dashboard for store managers.


## 🚀 Features
- Real-time cart and checkout flow
- Product creation and category management
- User authentication and role-based access
- Admin dashboard for order and user management
- Image upload and preview
- Light/dark mode support
- Mobile responsive UI with Tailwind CSS
- RTK Query-powered API handling


## 🛠️ Tech Stack
- **Frontend:** React, Tailwind CSS, React Router, Vite, Redux Toolkit
- **Backend:** Node.js, Express.js, MongoDB, Mongoose
- **Auth:** JWT, Role-based access
- **File Uploads:** Multer
- **Dev Tools:** ESLint, Prettier, Git, VS Code
- **Charts:** Recharts  
- **Deployment:** Vercel (Frontend) + Render (Backend)
